This is just a short post regarding Brexit. Setting aside economic, political and social considerations, there is another consequence: there is now one fewer country in the EU.

We will miss you, UK. We wish you the best.

**Historical example:** The mapping examples use **cartography**, which is now in maintenance mode. Its maintainers recommend [**mapsf**](https://riatelab.github.io/mapsf/) for new work. The original code and outputs are preserved and have not been revalidated against current package versions. {: .alert .alert-info .p-3 .mx-2 .mb-3 }

``` r
library(cartography)
library(sf)
library(giscoR)


#EU
eu <- giscoR::gisco_countrycode %>% filter(eu)

# Download maps
NUTS1 <- gisco_get_nuts(epsg = 3035, country = eu$ISO3_CODE, nuts_level = 1)


UK <- gisco_get_countries(country =  "GBR", epsg = 3035)

noplot = c("FRY", "ES7", "PT2", "PT3")
NUTS1_Clean = NUTS1 %>% subset(!NUTS_ID %in% noplot) %>%
  group_by(CNTR_CODE) %>% summarise(a=dplyr::n())

# Flag image
url = "https://upload.wikimedia.org/wikipedia/commons/thumb/b/b7/Flag_of_Europe.svg/800px-Flag_of_Europe.svg.png"

#Mask UK
flagcut = getPngLayer(NUTS1_Clean,
                       url)
# Full extent
flag = getPngLayer(NUTS1_Clean,
                       url, mask = FALSE)


par(mar = c(0, 0, 0, 0))
tilesLayer(flag, alpha = 150)
tilesLayer(flagcut, bgalpha = 0, add = T)
plot(st_geometry(UK),
     col = "white",
     border = NA,
     add = TRUE)
```
