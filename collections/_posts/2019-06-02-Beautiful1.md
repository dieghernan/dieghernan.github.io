Sometimes you want to produce maps with special layouts. I especially like maps
with modified geometries, e.g. simplifying the original shapes to squares or
dots. When searching the web, I found the fantastic post [Fishnets and
Honeycomb: Square vs. Hexagonal Spatial
Grids](https://strimas.com/post/hexagonal-grids/) by [Matt
Strimas-Mackey](https://strimas.com/#about), which was a huge inspiration (by
the way, don't miss [his blog](http://strimas.com/#posts), full of very
interesting pieces of work).

The only thing I was not completely comfortable with was that the post used the
[old-fashioned](https://r.geocompx.org/) **sp** package instead of my personal
favorite, the **sf** package. The post was published in 2016, and note that the
author has also moved to the **sf** package since then. So I decided to explore
further options with **sf**.

The approach is similar, using grids over a map and working with them, but with
[`st_make_grid()`](https://r-spatial.github.io/sf/reference/st_make_grid.html).
I also expanded it by grouping the grids and producing dots over the geometries.
So basically I produced five variations of the map:

| Type          | Replacement | Grouped |
|---------------|:-----------:|:-------:|
| **Fishnet**   |   Square    |   No    |
| **Puzzle**    |   Square    |   Yes   |
| **Honeycomb** |   Hexagon   |   No    |
| **Hexbin**    |   Hexagon   |   Yes   |
| **Pixel**     |     Dot     |   No    |

## Working with square grids

Let's use the `square` option of `st_make_grid()` and play a bit with it.


``` r
uk <- rnaturalearth::ne_download(50,
  type = "map_subunits",
  returnclass = "sf",
  destdir = tempdir()
) %>%
  filter(CONTINENT == "Europe") %>%
  filter(ADM0_A3 == "GBR") %>%
  # Projecting and cleaning
  st_transform(3857) %>%
  select(NAME_EN, ADM0_A3)

initial <- uk %>%
  # Iteration using indexes
  mutate(index_target = row_number())

uk_palette <- c(
  England = "#A33C45",
  Scotland = "#345F91",
  Wales = "#477C54",
  "Northern Ireland" = "#A7A6D5"
)
```

<div role="note" aria-label="Caution" class="callout-caution" markdown="1">
The `cellsize` should be set in the same unit as the projection (in this case,
meters). Smaller cells create denser grids and can use substantially more memory.
</div>


``` r
# Grid to sf
grid <- initial %>%
  st_make_grid(50 * 1000,
    # Kms
    crs = st_crs(initial),
    what = "polygons",
    square = TRUE
  ) %>%
  st_as_sf() %>%
  mutate(index = row_number())

# We identify the grids that belong to an entity by assessing the centroid
cent_merge <- grid %>%
  st_centroid() %>%
  st_filter(initial) %>%
  st_join(initial)

grid_new <- grid %>% inner_join(st_drop_geometry(cent_merge), by = "index")

# Fishnet
fish_geom <- grid_new %>%
  group_by(NAME_EN) %>%
  summarise(n = n(), do_union = FALSE)


# Now let's create the puzzle
puzzle_geom <- grid_new %>%
  # Avoid slivers
  st_buffer(0.5) %>%
  group_by(NAME_EN) %>%
  summarise(n = n(), do_union = TRUE) # The only difference is do_union

# Plot

fish_geom %>%
  mutate(label = "Fishnet") %>%
  bind_rows(
    puzzle_geom %>%
      mutate(label = "Puzzle")
  ) %>%
  mutate(label = forcats::fct_inorder(label)) %>%
  ggplot() +
  geom_sf(
    aes(fill = NAME_EN),
    colour = background,
    linewidth = 0.2,
    show.legend = FALSE
  ) +
  facet_wrap(~label) +
  scale_fill_manual(values = uk_palette)
```

## Going hex

Extremely easy. We just need to change the `square` parameter of
`st_make_grid()` from `TRUE` to `FALSE`.



## Pixel it!

For the dot map, use the centers of a hexagonal grid. Assign each center to a
region, then draw a circle with a radius set to 40% of the grid cell size.


``` r
grid_pixels <- initial %>%
  st_make_grid(50 * 1000,
    # Kms
    crs = st_crs(initial),
    what = "centers",
    square = FALSE
  ) %>%
  st_as_sf() %>%
  mutate(index = row_number())

pixels_geom <- grid_pixels %>%
  st_join(initial, left = FALSE) %>%
  # We need to buffer the points to get polygons, based on the grid resolution
  st_buffer(50 * 1000 * 0.4) %>%
  group_by(NAME_EN) %>%
  summarise(n = n(), do_union = FALSE)


# Plot
ggplot(pixels_geom) +
  geom_sf(
    aes(fill = NAME_EN),
    colour = background,
    linewidth = 0.2,
    show.legend = FALSE
  ) +
  scale_fill_manual(values = uk_palette) +
  labs(title = "Pixel")
```

## Wrap up

Finally, I wrapped all that in [`stdh_gridpol()`](https://github.com/dieghernan/dieghernan.github.io/blob/main/assets/functions/stdh_gridpol.R).


``` r
stdh_gridpol <- function(sf,
                         to = "fishnet",
                         gridsize = as.integer(
                           min(
                             diff(st_bbox(sf)[c(1, 3)]),
                             diff(st_bbox(sf)[c(2, 4)])
                           ) / 40
                         ),
                         sliver = 0.5) {
  if (!all(st_geometry_type(sf) %in% c("POLYGON", "MULTIPOLYGON"))) {
    stop("Input should be MULTIPOLYGON or POLYGON")
  }
  if (!to %in% c("fishnet", "puzzle", "honeycomb", "hexbin", "pixel")) {
    stop("'to' should be 'fishnet','puzzle','honeycomb','hexbin' or 'pixel'")
  }

  if (inherits(sf, "sf")) {
    initial <- sf
    initial$index_target <- 1:nrow(initial)
  } else {
    initial <- st_sf(index_target = 1:length(sf), geom = sf)
  }

  target <- st_geometry(initial)

  if (to %in% c("fishnet", "puzzle")) {
    sq <- T
  } else {
    sq <- F
  }
  if (to == "pixel") {
    grid <- st_make_grid(target,
      gridsize,
      crs = st_crs(initial),
      what = "centers",
      square = FALSE
    )
  } else {
    grid <- st_make_grid(
      target,
      gridsize,
      crs = st_crs(initial),
      what = "polygons",
      square = sq
    )
  }
  grid <- st_sf(index = 1:length(lengths(grid)), grid) # Add index
  if (to == "pixel") {
    cent_merge <- st_join(grid, initial["index_target"], left = F)
    grid_new <- st_buffer(cent_merge, gridsize * 0.4)
  } else {
    cent_grid <- st_centroid(grid)
    cent_merge <- st_join(cent_grid, initial["index_target"], left = F)
    grid_new <- inner_join(grid, st_drop_geometry(cent_merge), by = "index")
  }
  if (to %in% c("fishnet", "honeycomb", "pixel")) {
    geom <- aggregate(
      grid_new,
      by = list(grid_new$index_target),
      FUN = min,
      do_union = FALSE
    )
  } else {
    geom <- aggregate(
      st_buffer(grid_new, sliver),
      by = list(grid_new$index_target),
      FUN = min,
      do_union = TRUE
    )
  }
  if (inherits(sf, "sf")) {
    fin <- left_join(
      geom %>% select(index_target),
      st_drop_geometry(initial),
      by = "index_target"
    ) %>%
      select(-index_target)
    fin <- st_cast(fin, "MULTIPOLYGON")
    return(fin)
  } else {
    fin <- st_cast(geom, "MULTIPOLYGON")
    return(st_geometry(fin))
  }
}
# End of the function-----

fish <- stdh_gridpol(uk, to = "fishnet", gridsize = 50 * 1000)
puzz <- stdh_gridpol(uk, to = "puzzle", gridsize = 50 * 1000)
hon <- stdh_gridpol(uk, to = "honeycomb", gridsize = 50 * 1000)
hex <- stdh_gridpol(uk, to = "hexbin", gridsize = 50 * 1000)
pix <- stdh_gridpol(uk, to = "pixel", gridsize = 50 * 1000)
```


``` r
grid_maps <- bind_rows(
  list(
    Original = uk,
    Fishnet = fish,
    Puzzle = puzz,
    Honeycomb = hon,
    Hexbin = hex,
    Pixel = pix
  ),
  .id = "method"
) |>
  mutate(
    method = factor(
      method,
      levels = c("Original", "Fishnet", "Puzzle", "Honeycomb", "Hexbin", "Pixel")
    )
  )

ggplot(grid_maps) +
  geom_sf(
    aes(fill = NAME_EN),
    colour = background,
    linewidth = 0.2,
    show.legend = FALSE
  ) +
  scale_fill_manual(values = uk_palette) +
  facet_wrap(vars(method), nrow = 2) +

    title = "Redrawing the United Kingdom",
    subtitle = "Original boundaries and five representations on a 50 km grid"
  ) +
  theme(
    plot.title = element_text(size = 21),
    plot.subtitle = element_text(size = 13, margin = margin(t = 3, b = 12)),
```

And that's it! The function `stdh_gridpol()` has some alert mechanisms, such as
accepting only `POLYGON` or `MULTIPOLYGON`, and the default value of `gridsize`
is computed so that the shortest dimension has 40 cells.
