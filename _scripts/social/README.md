# Social cards

`social-card.html` combines the original `assets/img/site/banner.png` map
with Inter and Inter Tight, using the GitDev / GitDev Dark navy and blue.
The map's original magenta, orange, yellow and turquoise colors are preserved.

Serve the repository root over HTTP. Open `_scripts/social/social-card.html`,
wait for local fonts and the map to load and capture JPEG screenshots at
1200 × 630 (`assets/img/site/social-preview.jpg`) and 1280 × 640
(`assets/img/site/github-preview.jpg`). Use 100% browser zoom.

Font files retain their bundled OFL licenses.
